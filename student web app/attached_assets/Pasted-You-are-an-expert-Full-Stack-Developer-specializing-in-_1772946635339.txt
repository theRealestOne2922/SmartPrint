You are an expert **Full-Stack Developer specializing in Next.js, Supabase, and modern product UI design**.

I am building a **Smart Print Kiosk system** for a university campus.

The kiosk UI is already built and runs on a Raspberry Pi.
Students interact with the kiosk using a **6-digit Print ID** to retrieve their uploaded documents and complete payment.

Your task is to build the **Student Web Application** that allows students to upload documents and generate this Print ID.

The system must integrate with the existing backend stack.

# PURPOSE OF THE STUDENT WEB APP

Students use this app to:

Upload their document before going to the kiosk.

The system then generates a **unique 6-digit Print ID** that the student enters at the kiosk.

The kiosk then retrieves the document and handles payment.
