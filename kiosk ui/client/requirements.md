## Packages
framer-motion | Page transitions and animations for the kiosk interface
react-qr-code | To generate the mock UPI payment QR code
lucide-react | High quality icons for the kiosk interface

## Notes
Kiosk environment assumes a 1080p touch screen display.
Scrollbars are globally hidden via CSS to prevent user scrolling.
Text selection is globally disabled to prevent accidental highlights.
Includes dev-buttons for simulating payment and printing complete states (since hardware isn't attached).
